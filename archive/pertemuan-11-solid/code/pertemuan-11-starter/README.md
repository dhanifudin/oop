# Pertemuan 11 Starter: Order Processing

This is the "smelly" starting point for the Pertemuan 11 jobsheet (SOLID Principles). `OrderProcessor` mixes validation, discount calculation, file storage, and receipt printing in a single class. Your task is to refactor it into a SOLID-compliant design by following `jobsheets/id/pertemuan-11-solid-principles.md` (or the `en/` version).

Run it with Maven:

```bash
mvn -q compile exec:java
```

Or open the project directly in NetBeans (File > Open Project) and click Run Project.
