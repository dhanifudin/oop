  (`nilai[]`) disimpan terpisah dari fungsi yang mengolahnya
  (`hitungRataRata`), dan fungsi mana pun bebas mengakses data itu tanpa
  batasan apa pun.
---
Sebuah program catatan nilai mahasiswa ditulis seperti ini:

```java
double[] nilai = {80, 90, 75};

static double hitungRataRata(double[] nilai) {
    double total = 0;
    for (double n : nilai) {
        total += n;
    }
    return total / nilai.length;
}
```
