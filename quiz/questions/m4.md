answer: "Association"
explanation: >-
  Constructor Account menerima `owner` (Customer) sebagai parameter dari
  luar, bukan membuatnya sendiri, dan Account hanya menyimpan satu
  Customer saja (bukan koleksi). Ini pola association.
---
Diberi potongan kode berikut dari checkpoint Bank Mini:

```java
public class Account {
    private String accountNumber;
    private Customer owner;
    private double balance;

    public Account(String accountNumber, Customer owner, double balance) {
        this.accountNumber = accountNumber;
        this.owner = owner;
        this.balance = balance;
    }
    // getter, deposit, withdraw, printInfo
}
```

Kenapa relasi `Account`-`Customer` disebut association, bukan aggregation atau composition?

Diberi program berikut:

```java
Customer customer1 = new Customer("Nadia", "0812-0000-0001");
Account acc1 = new Account("A001", customer1, 500000);
acc1.withdraw(150000);

Customer customer2 = new Customer("Sari", "0812-0000-0002");
Account acc2 = new Account("A002", customer2, 200000);

Bank bank = new Bank(10);
bank.addAccount(acc1);
bank.addAccount(acc2);
bank.printAllAccounts();

Account found = bank.findAccount("A002");
if (found != null) {
    found.printInfo();
}
```
